# What-If Simulator — Plain English

You can ask "what if we drop price, add a promo badge, change the copy, or promise 2-day delivery?" The simulator runs these scenarios through behavior-based twins and shows:
1) What each twin would choose
2) A short reason grounded in what's on the page
3) The blended result for your audience or a user
4) The change vs the current page

We simulate only among options visible on the page. Results repeat for the same inputs. Twins remain distinct so you see who you win or lose when you change a page.
