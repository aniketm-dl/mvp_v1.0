🎯 WORKFLOW: Launch → Setup → Train → Download → Chat

┌─────────────┐
│   LAUNCH    │  make launch (or ./darpan.py launch)
│  AWS GPU    │  → Creates g5.xlarge spot instance
│  Instance   │  → Cost: ~$0.35/hr
└──────┬──────┘
       │
       ▼
┌─────────────┐
│    SETUP    │  make setup-instance (on EC2)
│ Environment │  → Installs CUDA, Python, deps
│             │  → Clones repo, downloads data
└──────┬──────┘  → Time: ~10 min
       │
       ▼
┌─────────────┐
│    TRAIN    │  make train (on EC2)
│  18 Persona │  → Trains all adapters
│  Adapters   │  → Auto-shutdown when done
└──────┬──────┘  → Time: ~90 min, Cost: ~$0.50
       │
       ▼
┌─────────────┐
│  DOWNLOAD   │  make download (local)
│   Models    │  → Syncs from S3
│   from S3   │  → Downloads adapters
└──────┬──────┘  → Size: ~400MB total
       │
       ▼
┌─────────────┐
│    CHAT     │  make chat (local)
│    with     │  → Interactive CLI
│  Personas   │  → Talk to 18 personas
└─────────────┘  → Test predictions
