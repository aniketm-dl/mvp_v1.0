## Next Steps

### 1. Get HuggingFace Token (Required)
1. Go to: https://huggingface.co/settings/tokens
2. Click "New token"
3. Name: `darpan-training`
4. Type: Read
5. Copy token (starts with `hf_...`)
6. Save it:
   ```bash
   export HF_TOKEN="hf_your_token_here"
   echo 'export HF_TOKEN="hf_your_token_here"' >> ~/.aws_training_env
   ```

### 2. Launch Training Instance
```bash
cd ~/mvp_v1.0
source ~/.aws_training_env

# Launch instance (interactive)
./scripts/aws/launch_training_instance.sh
```

### 3. Connect to Instance
After launching, you'll get an SSH command like:
```bash
ssh -i ~/.ssh/darpan-training.pem ubuntu@<INSTANCE_IP>
```

### 4. Setup Instance
On the EC2 instance, run:
```bash
bash <(curl -s https://raw.githubusercontent.com/aniketm-dl/mvp_v1.0/main/scripts/aws/setup_training_instance.sh)
```

### 5. Start Training
```bash
cd ~/mvp_v1.0
source venv/bin/activate
python scripts/aws/train_production.py --auto-shutdown
```
