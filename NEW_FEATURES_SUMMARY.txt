--------------------------------------------------------------------------------
HOW TO USE
--------------------------------------------------------------------------------

1. RUN CLUSTERING PIPELINE:

   python scripts/cluster_personas.py --interactive

   You'll be prompted for:
   - Number of personas (default: 10)
   - Clustering method (K-Means/GMM/HDBSCAN/Hierarchical)
   - LLM model for descriptions
   - Feature weights

   Watch live progress with:
   - Progress bars
   - Quality metrics
   - Status indicators

2. START API SERVER:

   uvicorn src.api.service:app --reload --port 8000

3. GET USER INSIGHTS:

   curl http://localhost:8000/user/u123/assignment

   Returns:
   - Primary persona
   - Feature importance (top 5)
   - Natural language explanation
   - Distances to all twins
   - Alternative personas
   - Confidence score

4. GET CLUSTER MAP:

   curl http://localhost:8000/metrics/cluster_map

   Returns 2D coordinates for visualization

5. GET HIERARCHY:

   curl http://localhost:8000/metrics/hierarchy

   Returns dendrogram and decision tree

--------------------------------------------------------------------------------
CUSTOMIZATION
--------------------------------------------------------------------------------

Edit CONFIGS/clustering/cluster_config.yaml:

# Number of personas
n_clusters: 10

# Clustering method
clustering_method: "kmeans"  # or "gmm", "hdbscan", "hierarchical"

# Feature weights
feature_weights:
  behavior: 0.5
  psychographic: 0.3
  demographic: 0.2

# Quality thresholds
separation_thresholds:
  silhouette_min: 0.35
  mean_jsd_min: 0.10
  ari_min: 0.80

# Progress tracking
verbosity: "verbose"  # "quiet", "normal", "verbose", "debug"
show_progress: true
